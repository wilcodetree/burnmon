# BurnMon v0.2.2 patch: Now page chart and fixes (2026-09-23)

Runs after v0.2.1 (the hang patch) is committed, before V3-1. Model: Sonnet. Tag `v0.2.2`.
Source: Wilco's review of the Now page, 2026-09-23 around 12:00, three screenshots.

## Items

N1. The turn drawer cannot be closed. The X and the overlay click both call
`closeTurnDrawer()` in `internal\report\template.html`, and the CSS looks right, so first
reproduce it. Check whether the window is frozen (the v0.2.1 hang) or something reopens the
drawer (a poll, a chart click handler). Fix the cause. Add Esc to close.

N2. "Live burn, last 30 minutes" becomes a clustered bar chart, one bar per running session
per minute, bars side by side inside each minute.
- Slots are whole minutes, the last 30 closed minutes plus the current one, which grows.
  This replaces F8's 10-second slots. Keep F8's other rules: one Chart.js instance,
  `update('none')`, no height animation, damped Y max.
- X axis: a tick and a light gridline every minute, labels `11:40`, `11:41` to `12:10`.
  Label every minute when there are at least 40 px per label, else every 5 minutes. Never
  rotate labels.
- Left axis in tokens with K, M and B (`850K`, `1.2M`). The same format in the tooltip.
- Right axis (cost) shows only while the cost series is on; hidden by default, as now.
- Colours: one hue family per vendor, one shade per client type. Claude: warm (Claude
  Code darkest, Cowork lighter). Codex: green (CLI dark, desktop lighter). Copilot: blue
  (CLI dark, VS Code lighter). Hermes: violet. Two sessions of the same vendor and type get
  two further steps of the same shade. Take the values from the template's existing colour
  tokens where one fits, and check light and dark mode.
- No finding markers on this chart: remove the context-runway and expensive-turn points
  and their legend items. Findings stay in the turn ticker, the drawer and the session card.
- Clicking a bar opens the drawer for the largest turn of that session in that minute.

N3. More space between the chart panel and the session cards (at least the gap used
between other sections on the page).

N4. Vendor strip cells keep their History link but look like plain numbers: no blue, no
underline; underline plus a tooltip "Open in History" on hover.

N5. Wrong context window. The Claude Code card for `claude-sonnet-5` says "window in book:
200K, exceeded" and "about 0 turns to 80%". The 2026-09-22 live-docs check (42A) found
Sonnet 5 has a 1M-token window. Correct the context-window book for every model the 42A
finding names, re-date it, and make sure runway uses the corrected value.

N6. The Codex card and legend show "(model unknown)". Check the live rollout for the model
field; fix the Codex adapter if the model is in the trail, else keep the label and say why
in `SESSION_LOG.md`.
