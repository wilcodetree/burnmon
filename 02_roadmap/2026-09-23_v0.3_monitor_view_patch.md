# BurnMon v0.3, V3-3c: monitor view like perfadvisor (U5, 2026-09-23)

Follow-up to V3-3b. Model: Sonnet. No tag. Source: Wilco's review of the first monitor
view, 2026-09-23, with two reference images saved in `testdata\uicheck\reference\`:
`perfadvisor_history.png` (the chart he wants) and `monitor_mockup.jpg` (the layout he
wants; the chart data and the repeated cards in it are placeholders).

## What is wrong now

The live burn chart in dev-mode monitor view is a tiny strip of block characters in the
top right. The chart title is cut off ("claude-code · claude-son"). Text is small.

## U5, what to build

Chart, modelled on perfadvisor's "history, newest right" panel (read
`C:\ZND\projects\perfadvisor\internal\tui\widgets.go`, `graph()`, and
`C:\ZND\projects\perfadvisor\internal\tui\view.go`, `graphLines()`, before writing it):
- Braille dots (U+2800 block, 2 x 4 dots per character cell), full content width, about
  35% of the window height, dark panel, newest on the right, 30-minute window.
- One series per running session, overlaid, in that session's vendor colour from the
  v0.2.2 colour table. Dots, not solid blocks, so overlapping series stay readable.
- Time resolution follows the dot columns: `bmLive` gains an optional bucket-size
  argument, 10 seconds in monitor view, 60 seconds in full view (same call, no new
  binding).
- Header above the chart, perfadvisor style: title "live burn, newest right", then one
  legend line with a coloured dash, the full session label (vendor · model · project,
  never cut off; wrap to a second line if needed) and its current tokens per minute
  (K, M, B, two decimals). Right end of the line: "scaled to peak 5.10M".
- Minute labels under the chart every 5 minutes.

Session cards: a grid, four per row, wrapping, all the same width. ASCII borders line up:
compute the box width in characters and pad every line to it, so the right border is
one straight column.

Size: everything bigger. Base font 16 px, chart header 18 px, vendor strip 20 px, scaling
with the window width (CSS `clamp`). Monospace stack: Cascadia Mono, JetBrains Mono,
Consolas. Check that braille glyphs render in that stack on this laptop; if not, add a
fallback font that has them.

Business mode keeps the normal visuals; this patch changes dev-mode monitor view only.
